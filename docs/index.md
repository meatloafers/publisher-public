# Publisher

Publisher is a locally operated application for creating original narrated media and publishing videos to the owner's YouTube channel.

Publisher uses the YouTube Data API Services to upload videos after the channel owner explicitly authorizes access through Google OAuth.

The application is not a public video hosting service and does not provide access to other users' YouTube accounts. It is primarily used by its owner to prepare and publish original content.

## YouTube integration

When publishing a video, Publisher allows the user to control information including:

* Video title
* Video description
* Video file
* Video visibility, such as private, unlisted, or public

Publisher only performs a YouTube upload after the user initiates or approves the publishing action.
